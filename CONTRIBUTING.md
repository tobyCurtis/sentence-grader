# Contributing 💜

Thanks for helping teachers save a little time!

1. Open an issue describing the bug or enhancement.
2. Use **fictional** student responses. Never share real classroom data.
3. Keep functionality on-device and avoid unnecessary permissions or remote dependencies.
4. Add tests for changes to sentence-counting behavior.
5. Run `npm run check` before proposing a pull request.

Google Forms can change its generated markup. Favor accessible selectors, conservative behavior, and explicit teacher control.

Friendly, silly new toast messages are welcome. 🎺
