# Privacy

Sentence Grader helps teachers grade writing responses **without sending student data to a third party**.

## Data processed

On the Google Forms editor page, the extension reads visible answer text and score-field values into memory for sentence counting and preview. This information is not sent to external servers, used for analytics, or retained in extension storage.

## Data stored

Chrome extension storage holds only local preferences: toast, confetti, and sound toggles, plus the optional grader display name (default: Berlin). No student names, identifiers, answers, scores, or Form IDs are stored.

## Network requests

Sentence Grader makes no network requests of its own. Google Forms itself communicates with Google's servers when used and when grades are saved.

## Debug logs

Console diagnostics include event names and progress counts, not student answer text.

## Classroom use

Teachers should verify compatibility with their current Forms editor and follow applicable school data policies. This is an independent helper, not an official Google product or a replacement for teacher judgment.
